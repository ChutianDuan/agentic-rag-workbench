## 非外键逻辑关联

```mermaid
flowchart TB
    UA["user_account"] -. "memory_message_id → id" .-> M["messages"]
    S["sessions"] -. "summary_message_id → id" .-> M

    RM["request_metrics"] -. "session_id → id" .-> S
    RM -. "doc_id → id" .-> D["documents"]
    RM -. "user_message_id → id" .-> M
    RM -. "celery_task_id → celery_task_id（可能）" .-> T["tasks"]

    VJ["vector_index_jobs"] -. "celery_task_id → celery_task_id（可能）" .-> T
    T -. "entity_type + entity_id 多态关联" .-> E["documents / chunks / sessions / 其他实体"]
```
